
# Alert System Using Buzzer and LED

## About the Project
This project uses Arduino UNO and an Ultrasonic Distance Sensor to detect nearby objects. When an object comes within a specified distance, the LED glows and the buzzer gives an alert.

## Components Used
- Arduino UNO
- Ultrasonic Distance Sensor
- Buzzer
- LED
- Breadboard
- Jumper Wires

## Working Principle
1. Ultrasonic sensor detects nearby objects.
2. Arduino measures the distance.
3. LED turns ON when an object is detected within the set distance.
4. Buzzer produces an alert sound.
